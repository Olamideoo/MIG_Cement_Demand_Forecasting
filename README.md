# MIG Cement Demand Forecasting

A time-series forecasting project for predicting cement demand across multiple construction sites using historical operational data, weather conditions, inventory records, and planned concrete pours.

## Technologies
- Python
- Pandas
- SQLite
- Plotly Dash
- Scikit-learn
- Statsmodels

## Objective
Forecast cement demand up to 8 weeks ahead and support inventory optimisation.
